[1] 새 모듈 가져오기

  2. 메뉴 [파일] -> [파일 가져오기] -> 이 폴더의 mod_FirebaseAuth.bas 선택
  3. 왼쪽 목록에 mod_FirebaseAuth 가 생기면 더블클릭

     Firebase 에서 만든 excel-sync@f2telecom.com 의 비밀번호를 입력

[2] Module2 에서 4군데 수정  (Ctrl+F 로 찾기)

  ① 진행내역 가져오기  - 찾을 내용:  documents/Sheet2Data/List?t=
     그 아래쪽의
         http.Open "GET", url, False
     바로 다음 줄에 추가:
         SetAuthHeader http

  ② 팀일정 가져오기  - 찾을 내용:  documents/CalendarData/
     그 아래쪽의
         http.Open "GET", url, False
     바로 다음 줄에 추가:
         SetAuthHeader http

  ③ 업로드 (SendToFirestore)  - 찾을 내용:  Sub SendToFirestore
     Sub SendToFirestore ... End Sub 전체를 아래로 교체:

Sub SendToFirestore(col As String, docID As String, jsonBody As String)
    Dim strURL As String, objHTTP As Object
    Static lastWarn As Date
    strURL = "https://firestore.googleapis.com/v1/projects/" & PROJECT_ID & "/databases/(default)/documents/" & col & "/" & docID
    Set objHTTP = CreateObject("MSXML2.XMLHTTP")
    On Error Resume Next
    With objHTTP
        .Open "PATCH", strURL, False
        .setRequestHeader "Content-Type", "application/json"
        SetAuthHeader objHTTP
        .send jsonBody
    End With
    ' 업로드 실패하면 알려주기 (30초에 한 번만)
    If Err.Number <> 0 Or objHTTP.Status <> 200 Then
        If Now - lastWarn > TimeSerial(0, 0, 30) Then
            lastWarn = Now
            MsgBox "앱으로 업로드 실패: " & col & "/" & docID & vbCrLf & _
                   "(" & objHTTP.Status & ") " & Left(objHTTP.responseText, 200), _
                   vbExclamation, "업로드 실패"
        End If
    End If
    On Error GoTo 0
End Sub
